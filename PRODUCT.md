## Platform

web

## Users
Technical recruiters, engineering hiring managers, and senior tech leads evaluating Jude for engineering roles in applied AI, machine learning telemetry, and full-stack web development.

## Product Purpose
To showcase Jude's engineering capability, technical rigor, and product craft. The portfolio demonstrates end-to-end execution across applied AI/computer vision systems and production-grade, highly responsive web applications, converting technical evaluators into high-signal interview opportunities.

## Positioning
Applied AI & Full-Stack Engineer — bridging production machine learning and computer vision systems with high-craft, performant web applications. Jude's work highlights real-world deployment, real-time edge telemetry (e.g. 60 FPS ocular tracking for sleep deprivation detection, WFP commodity pricing engines), and robust modern web architecture.

## Operating Context
- Evaluators reviewing the site on desktop and mobile screens during candidate screening rounds.
- Fast evaluation workflows: recruiters spend 30–60 seconds scanning hero metrics, featured projects, tech stack badges, and resume links.
- In-depth technical review: engineering leads drill into project architectures, live interactive demos, GitHub repos, and clinical/applied telemetry details.

## Capabilities and Constraints
- Framework & Tech: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS, Lenis smooth scrolling, Sonner notifications, Lucide icons.
- Deployed surfaces and live demo integrations (e.g. LPU Health Monitoring, Pamilihan AI, Subtrace).
- High visual craft floor: responsive down to mobile viewports, strict luminance hierarchy, fast initial load, accessible touch targets, and authentic telemetry metrics.
- Preserves genuine credentials and thesis history (Lyceum of the Philippines University - Cavite, Certiport certifications).

## Brand Commitments

## Product Principles
1. **Proof Over Posturing**: Ground every project in verified technical mechanics, telemetry metrics, and real working code rather than vague summaries.
2. **Speed to Signal**: Allow evaluators to grasp the depth of engineering competence in 10 seconds, while providing deep-dive architecture specs for thorough technical scrutiny.
3. **Dual Competence**: Clearly articulate both systems-level AI/ML engineering (computer vision, CNNs, edge inference) and modern full-stack web craftsmanship (Next.js, React 19, responsive UI).
4. **Performance & Reliability as Table Stakes**: The portfolio itself must embody the engineering standards it claims—zero layout jank, instantaneous interactions, and rock-solid responsiveness.

## Accessibility & Inclusion
- High-contrast text meeting WCAG AA standards across both themes.
- Accessible focus states and interactive hit targets (minimum 44px on mobile).
- Semantic headings and aria labels for custom interactive components and modals.
