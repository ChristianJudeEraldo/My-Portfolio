# Interactive Task & State Management System

A focused engineering study on immutable state transitions, dynamic list reordering, and client-side storage persistence in React 19.

---

## Architectural Objectives

- **Predictable State Transitions**: Structured array manipulation with pure functional updater patterns.
- **Dynamic Task Prioritization**: Real-time positional reordering (Move Up / Move Down) with index boundary guards.
- **Persistent Storage**: Local storage synchronization with fallback initialization.
