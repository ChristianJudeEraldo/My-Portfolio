# Interactive To-Do List

This project was developed to practice **React State management** and dynamic array manipulation.

## **Learning Objectives:**
- Implementing `useState` for dynamic lists.
- Handling user input and event listeners.
- Logical task reordering (Move Up/Down).

You can interact with the component directly below:
