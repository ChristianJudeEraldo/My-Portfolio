# CNN-Based Facial Recognition for Sleep Deprivation Detection

An undergraduate Computer Engineering thesis applying deep learning and computer vision to classify physiological markers of fatigue and sleep deprivation in students.

---

## Project Overview

Sleep deprivation directly affects cognitive focus, physical reaction time, and academic performance. This project explores automated detection of fatigue through real-time facial feature extraction and deep convolutional neural networks.

## Technical Architecture & Methodology

- **Data Pipeline & Preprocessing**: Facial landmarks and ocular region extraction with OpenCV and MediaPipe.
- **Model Architecture**: Convolutional Neural Network (CNN) pipeline implemented in TensorFlow/Keras for multi-class fatigue classification (alert, moderately fatigued, sleep-deprived).
- **Inference & UI**: Lightweight inference dashboard built with Next.js and Tailwind CSS for real-time telemetry and logging.

## Core Toolchain
- **Deep Learning**: Python, TensorFlow, Keras
- **Computer Vision**: OpenCV, MediaPipe
- **Application & Dashboard**: Next.js 16, TypeScript, Tailwind CSS
